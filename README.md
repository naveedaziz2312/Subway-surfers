# Subway Surfers Clone 🏃‍♂️💨

A simple and fun endless runner game inspired by Subway Surfers, built with HTML, CSS & JavaScript.

![Game Banner](https://img.shields.io/badge/Game-Endless%20Runner-yellow?style=for-the-badge)
![Tech](https://img.shields.io/badge/Built%20With-HTML%20%7C%20CSS%20%7C%20JS-blue)

## 🎮 Live Demo
Play the game: `https://YOUR_USERNAME.github.io/subway-surfers-game/`

## ✨ Features
- 🏃 Smooth 3-lane running gameplay
- 🚂 Random train obstacles
- ⬅️➡️ Swipe & Arrow key controls
- ⬆️ Jump to avoid obstacles
- 🏆 Score system
- 📱 Mobile friendly (Touch & Swipe support)
- 💥 Game Over & Auto Restart

## 🕹️ How to Play
- **Left Arrow / Swipe Left** - Move Left
- **Right Arrow / Swipe Right** - Move Right
- **Up Arrow / Swipe Up** - Jump
- Avoid trains and make high score!

## 🛠️ Tech Stack
- HTML5
- CSS3 (Animations & Gradients)
- Vanilla JavaScript (No Framework)

## 📁 Files
- `index.html` - Main game structure
- `style.css` - Game styling & lanes
- `script.js` - Game logic & controls

## 🚀 How to Run
1. Clone this repo
2. Open `index.html` in browser
3. Start playing!
